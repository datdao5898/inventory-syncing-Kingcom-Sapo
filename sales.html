Hướng dẫn sử dụng

Trang này tổng hợp doanh thu sàn từ đơn hàng Sapo và hiệu quả quảng cáo Shopee từ file xuất của Shopee, theo mẫu Shopee Ads Weekly Tracker.

Quy trình mỗi sáng thứ 2 (báo cáo tuần trước)

  1. Lấy doanh thu Sapo: bấm Tuần trước ở đầu trang (tự chọn thứ 2 – chủ nhật tuần trước), đợi 1–2 phút.
  2. Xuất file từ Quảng cáo Shopee cho từng gian, chọn đúng khoảng thời gian thứ 2 – chủ nhật tuần trước, tải về dạng .csv:
    • Quảng cáo Sản phẩm (Dịch vụ Hiển thị Sản phẩm) – file có cột "Mã sản phẩm".
    • Quảng cáo Shop (Dịch vụ Hiển thị Shop) – nên dùng bản theo từ khóa (Keyword Level) để xem được từng từ khóa.
  3. Tải file lên: vào tab Quảng cáo Shopee, bấm ＋ Tải file Quảng cáo Shopee hoặc kéo thả, chọn được nhiều file cùng lúc. Tool tự nhận gian hàng, loại quảng cáo và kỳ trong file, rồi tự lấy doanh thu Sapo đúng kỳ đó (không cần bấm gì thêm, đợi 1–2 phút).
  4. Gán SKU cho sản phẩm mới chạy quảng cáo (chỉ làm 1 lần cho mỗi sản phẩm, xem mục bên dưới).
  5. Xem đánh giá trên tab Quảng cáo, rồi bấm Tải Excel để lưu / gửi báo cáo.

💡 Không cần lấy doanh thu trước: tải file Shopee lên là tool tự đọc ngày trong file và tự lấy doanh thu Sapo cùng kỳ. Chọn kỳ khác ở ô Kỳ … trong tab Quảng cáo cũng tự lấy. Nếu Sapo lỗi mạng, bấm nút "Lấy doanh thu Sapo kỳ này" để thử lại. Lưu ý: mỗi lúc chỉ xem 1 kỳ, nên tab Tổng quan / Sản phẩm và file Excel cũng chuyển theo kỳ đó.

Gán Saleman cho gian hàng

Tab Tổng quan gian hàng → cột Saleman: chọn Evelyn / Boni / Ivy hoặc gõ tên khác, tự lưu. Chỉ cần làm 1 lần, tên saleman hiện trong bảng Quảng cáo và file Excel.

Gán SKU (vì sao và cách làm)

Shopee và Sapo gọi cùng 1 sản phẩm bằng 2 mã khác nhau (ví dụ Shopee 26303056546 = Sapo GZLM3). Tool cần biết 2 mã này là 1 để lấy doanh thu Sapo tính TACOS. Sản phẩm chưa gán hiện chữ đỏ Chưa gán:

  • Bấm vào SKU gợi ý nếu đúng → lưu ngay.
  • Sản phẩm có nhiều phân loại (màu, ngàm Canon/Sony…) → bấm "dùng cả N", hoặc bấm gán rồi gõ nhiều SKU cách nhau dấu phẩy.
  • Gợi ý sai / không có → bấm gán, gõ hoặc chọn SKU đúng trong danh sách, Enter để lưu.
  • Nút "Chỉ hiện SP chưa gán" giúp gán nhanh. Gán 1 lần, tool nhớ cho các tuần sau.

⚠ Gợi ý dựa theo tên nên cần xem kỹ: "M40 Combo" (GZLM3) khác "M40 SE Combo" (GZLM9).

File Excel gồm gì

  • Tổng Quan – trình bày như file mẫu sếp gửi; mỗi gian Shopee 1 dòng + dòng Tổng: saleman, tổng đơn, doanh thu, AOV, bán chạy nhất, thương hiệu, chi phí QC Sản phẩm / Shop, đơn và doanh số QC, CPO, tỷ trọng đơn / DT QC, ROAS, ACOS, TACOS, CTR, CR, đánh giá.
  • Chi Tiết – chi tiết từng sản phẩm, QC Shop và từ khóa (khi đã tải file QC cùng kỳ), có thêm giỏ hàng và chuyển đổi trực tiếp.
  • Top Sell – mỗi gian 1 khối Top 10 sản phẩm bán chạy (theo số lượng), in đậm = bán ≥ 30 cái.
  • Thương hiệu – thương hiệu bán chạy theo số lượng (tất cả gian và từng gian).

Câu hỏi thường gặp

TACOS hiện "–"?
Đang tự lấy doanh thu Sapo (đợi 1–2 phút), Sapo bị lỗi (bấm "Lấy doanh thu Sapo kỳ này" để thử lại), hoặc sản phẩm chưa gán SKU.
Tải lại file của cùng gian, cùng tuần thì sao?
File mới thay file cũ (theo từng loại Sản phẩm / Shop), không bị cộng 2 lần. File QC Shop bản chiến dịch và bản từ khóa là cùng số tiền, chỉ cần 1 trong 2.
Tải nhầm file?
Bấm Xoá file ở dòng gian hàng trong bảng Quảng cáo (bấm 2 lần để xác nhận).
Doanh số từ QC (Shopee) lớn hơn doanh thu Sapo?
Bình thường: số Shopee chưa trừ đơn huỷ, hoàn, voucher; doanh thu Sapo đã trừ.
Mở trang thấy trống số liệu?
Hệ thống vừa cập nhật hoặc khởi động lại: bấm Tuần trước / Lấy dữ liệu lại. File QC, SKU đã gán và saleman vẫn còn nguyên.
Thương hiệu lấy từ đâu?
Sapo không lưu thương hiệu nên tool lấy chữ đầu tên sản phẩm (Ulanzi, Zhiyun, Telesin…).

Quảng cáo Shopee

Tải file .csv xuất từ Quảng cáo Shopee (Sản phẩm hoặc Shop, mỗi file 1 gian) · tool tự đọc ngày trong file và tự lấy doanh thu Sapo cùng kỳ để tính TACOS

Các chỉ số nghĩa là gì?
ROAS = doanh số từ QC ÷ chi phí QC (bỏ 1 đồng thu về bao nhiêu đồng; càng cao càng tốt, cảnh báo khi < 8).
TACOS = chi phí QC ÷ doanh thu Sapo của các SP chạy QC × 100 (tốt: 8–12%; cao quá = tốn QC, thấp = còn dư địa tăng ngân sách). QC Shop chia cho doanh thu cả gian.
CTR = click ÷ lượt xem (cảnh báo khi < 6% → xem lại ảnh, tiêu đề). CR = đơn từ QC ÷ click (cảnh báo khi < 3% → xem lại giá, mô tả).
ACOS = chi phí QC ÷ doanh số QC. CPO = chi phí QC ÷ đơn từ QC. TACOS cả gian = chi phí QC ÷ doanh thu cả gian (công thức file mẫu). Tỷ trọng đơn / DT QC = đơn, doanh số từ QC ÷ tổng đơn, doanh thu cả gian.
Chuyển đổi trực tiếp = chỉ tính đơn, doanh số của đúng sản phẩm được quảng cáo.
Gán SKU: mã sản phẩm Shopee khác SKU Sapo, cần gán 1 lần để tính TACOS; tool nhớ cho các kỳ sau.
